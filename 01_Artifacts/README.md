# Artifacts and recovery

Use `Creator_Interviews/`, `Recollections/`, and `Recovered_Concepts/` for source-linked working records, not duplicate raw originals. Store unchanged approved source packages under [archive](../archive/README.md).

A recovered concept is an interpretation with provenance, not canon. Distinguish creator testimony, assistant synthesis, manuscript evidence, and research. Record incomplete captures and uncertain identities. Use the [source register](../00_Project/Source_Register.md) and [atomic-claim template](../09_Tools/Templates/Atomic_Claim.md).
