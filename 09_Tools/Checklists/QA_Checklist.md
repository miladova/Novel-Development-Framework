# Review checklist

- [ ] Correct project and isolated story universe
- [ ] Explicit author permissions for each operation
- [ ] Source bytes unchanged and checksums stored
- [ ] Sources anchored and speakers verified
- [ ] Missing/partial data labeled
- [ ] Interview questions nonrepeating and relevant
- [ ] Staged claims atomic with source references
- [ ] Conflicts and intentional mysteries visible
- [ ] Canon entries have explicit author decisions
- [ ] Canon index and dependent links current
- [ ] Manuscript chronology and names consistent
- [ ] Voice, POV and author-directed narrative scale respected
- [ ] No source or AI inference silently promoted
- [ ] Publication approval recorded separately
