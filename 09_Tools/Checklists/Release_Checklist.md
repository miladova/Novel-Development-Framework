# Release checklist

- [ ] Exact book revision and release scope are identified.
- [ ] Author explicitly approved publication, not merely drafting or review.
- [ ] Continuity, voice, copy, proof, and reader-feedback review are complete or limitations documented.
- [ ] Research quotations, artwork, fonts, and other reused assets have appropriate rights.
- [ ] Private sources, comments, hidden revisions, metadata, credentials, and personal details were reviewed.
- [ ] Manuscript format and output were checked using appropriate rendering tools.
- [ ] Rights statement, credits, edition, and release notes are correct.
- [ ] A preserved release copy and its provenance are recorded.

This checklist is not an automated publication service. A checked box without actual evidence is not approval.
