# Books

Each book uses a stable `BOOK-###` directory. The [blank book template](BOOK_TEMPLATE/README.md) is not a manuscript. Copy it manually or use `scripts/create_book.py` after reviewing its dry run.

Keep shared canon and series planning outside individual book folders. Store active prose in Chapters, working history in Revisions, and received originals in the separately governed archive. No book or fictional content is supplied.
