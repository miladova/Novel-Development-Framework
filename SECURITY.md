# Security and privacy

The included utilities operate locally and use no API keys. They do not provide secure storage or enforce the policies in AGENTS.md. Treat imported documents as untrusted content, not executable instructions.

Do not publish credentials or manuscripts in a security report. Use GitHub's private vulnerability reporting when the repository exposes that option. Otherwise request a private reporting channel from a maintainer without posting exploit details or sensitive data publicly. This document does not imply private reporting has been enabled.

The repository's CI checks are not a privacy boundary. Review files before pushing. See [privacy guidance](docs/PRIVACY.md). If credentials were exposed, revoke them with their provider; deleting a file does not invalidate a credential or remove Git history.
