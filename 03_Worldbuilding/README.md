# Worldbuilding workspace

Everything here is development material unless separately promoted to canon. Use the [character](../09_Tools/Templates/Character.md), [relationship](../09_Tools/Templates/Relationship.md), [location](../09_Tools/Templates/Location.md), and [timeline-event](../09_Tools/Templates/Timeline_Event.md) templates as needed.

Store character work in `Characters/` and setting work in `Locations/`. Link approved facts from canon, and mark unresolved mechanics or tentative possibilities clearly. Do not create detailed worldbuilding solely to fill a folder.
