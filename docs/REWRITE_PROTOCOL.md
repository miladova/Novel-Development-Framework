# Rewrite and drafting protocol

1. Identify authorized original baseline and any later author decisions.
2. Produce contradiction map and reconstruction timeline before line editing.
3. Interview for missing causality, setting rules, motivations, sequence, tone and deliberate ambiguity.
4. Obtain author review of the full story architecture and narrative scale; never assume conventional chapter pacing.
5. Build a scene registry and note each scene's narrative change and continuity dependencies.
6. Before prose, give a Writing Context Brief: branch/commit, approved canon, architecture, current manuscript continuity, relevant development material, unresolved questions and explicit inferences.
7. Wait for explicit prose-generation approval.
8. Draft bounded material and run chronology, nomenclature, relationship, style, and canon checks.
9. Save distinct revisions and prepare author review; never self-publish.
